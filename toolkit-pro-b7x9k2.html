Guida alle 8 Funzioni

Elimina in modo sicuro i "file dinosauro" che ingombrano il disco:

  • ✓ %TEMP% e C:\Windows\Temp — file temporanei (spesso 1–5 GB)
  • ✓ C:\Windows\Prefetch — cache avvio obsoleta
  • ✓ Log di sistema (Windows\Logs + Panther)
  • ✓ Svuotamento $Recycle.Bin di tutti gli utenti
  • ✓ DNS Cache (risolve errori di navigazione)
  • ⚠️ C:\Windows.old — vecchia installazione Windows (20–40 GB). Irreversibile: dopo la cancellazione non puoi tornare alla versione precedente.

Backup veloce e intelligente usando Robocopy con 16 thread paralleli (/MT:16).

Modalità COPY (sicura)

Aggiunge/aggiorna file, non elimina mai nulla dalla destinazione. Ideale per backup cumulativi.

Modalità MIR (specchio)

Copia esatta della sorgente. Attenzione: i file eliminati dall'originale vengono eliminati anche nel backup!

💡 Drag & Drop: Puoi trascinare la cartella sorgente/destinazione direttamente nella finestra CMD quando lo script lo richiede.

Esegue in sequenza ottimale i 4 passaggi di riparazione:

  1. 1. SFC /scannow — confronta ogni file di sistema con la copia Microsoft e li ripara
  2. 2. DISM /ScanHealth — analizza l'immagine Windows per danni
  3. 3. DISM /RestoreHealth — scarica e ripara da Microsoft (richiede Internet)
  4. 4. DISM /StartComponentCleanup — rimuove componenti obsoleti da WinSxS

Durata stimata: 10–30 minuti. Non interrompere il processo.

Ripristina completamente la configurazione di rete. Puoi scegliere un'operazione singola o "tutte insieme".

⚠️ Riavvio necessario dopo il reset completo per applicare tutte le modifiche.

Tre livelli di occultamento tramite attributi NTFS:

  • 👁 Nascondi — attrib +h: scompare da Explorer, ma visibile con "Mostra file nascosti"
  • 🙈 Super-Nascondi — attrib +h +s +r: invisibile anche con "Mostra file nascosti" attivo. Solo chi conosce il percorso esatto può accedervi.
  • ✅ Rendi Visibile — attrib -h -s -r: rimuove tutti gli attributi
[6] Gestione Spazio: tabella disco per partizione (totale/libero/usato/%), top 20 file più grandi (>1 GB) nella cartella utente, dimensione cartelle sistema pesanti.
[7] Processi Sospetti: lista processi con percorso eseguibile completo, connessioni di rete attive con processo associato, Run keys del registro (avvio automatico), possibilità di terminare un processo per PID.
[8] Snapshot Rapido: genera in pochi secondi un file .txt con versione OS, uptime, spazio disco per partizione, top 10 processi per CPU, configurazione rete. Utile per condividere lo stato del sistema con un tecnico.

💡 Tips & Trucchi da Esperto

  • → Drag & Drop: in qualsiasi funzione che richiede un percorso, puoi trascinare la cartella direttamente nella finestra CMD — il percorso si inserisce automaticamente.
  • → Robocopy /MT:16: usa 16 thread paralleli, riducendo i tempi di backup fino al 60% rispetto al normale copia-incolla.
  • → Prima della pulizia: esegui lo Scanner FREE per avere un "prima" documentato. Poi esegui la pulizia. Poi riesegui lo Scanner per il "dopo" e confronta.
  • → Processi sospetti: copia il percorso di un eseguibile insolito e cercalo su virustotal.com.
  • → Ctrl + C: interrompe immediatamente qualsiasi operazione in corso.
